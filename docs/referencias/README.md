# Referencias de tiendas

Tiendas estudiadas para mejorar el código maestro de Nevux (`public/nevux-master-pro.html`).
Cada documento registra **qué hace la tienda** y **cómo lo hacemos mejor en Nevux**.

**Regla:** de estas tiendas se replica la idea, nunca su código, sus textos ni sus imágenes.
Cada pieza de Nevux se escribe desde cero y usa datos reales de la tienda del cliente.
